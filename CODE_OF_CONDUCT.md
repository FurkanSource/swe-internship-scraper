# Code of Conduct

## Our standards

Be respectful, specific, and constructive. Welcome contributors with different experience levels. Discuss code and evidence without attacking people. Do not harass, threaten, discriminate, publish private information, or disrupt project spaces.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile. Maintainers may edit or remove content and may temporarily or permanently restrict participation when needed to protect contributors.

This policy applies in repository discussions, reviews, issues, and project events.
