# Support policy

Use GitHub Discussions for usage questions and GitHub Issues for reproducible defects or provider contract changes.

Include the provider, sanitized target shape, command, Python version, traceback, and whether the failure is repeatable. Do not post API keys, applicant data, cookies, private portal URLs, or resumes.

Supported releases receive fixes on the latest stable minor line. Release candidates receive compatibility fixes until the corresponding stable release. Experimental plugins use independent 0.x versions and may change when public markup changes.

Security reports follow [SECURITY.md](SECURITY.md).
